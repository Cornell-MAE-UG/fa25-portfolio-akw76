Here is a problem from Homework 5, and my answer. I found this problem useful because it synthesized topics we had learned from the entire first half of the semester, and so it was kind of fun to do. The first part was a control volume analysis to find steady state temperature, which was a topic we learned about in the first few weeks. The second part is a lumped capacitance method question where I had to find the formula for wire temperature as a function of time after t=0. This used topics we learned in the last couple lectures, so it was interesting to tie it back into a problem with earlier topics. This helped me become accustomed to broad heat transfer problems that use lumped capacitance method to find transient solutions.
